# Changelog

All notable changes to AI Morning Letter are recorded here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [2.0.0] — 2026-07-27

### Added
- README.md, LICENSE, CHANGELOG.md, tightened .gitignore (repo hygiene).
- Per-day OG image (`d/<date>/og.png`, 1200 × 630 PNG) generated by new `scripts/render_og.py` (Pillow).
- Per-day `<head>` carries `og:image` / `og:image:width` / `og:image:height` / `twitter:image`.
- Kicker-chip filter row above the archive search box (MODEL..OPEN-SOURCE, AND-combined, live counts, `/` keyboard shortcut to focus search).
- 20 editions backfilled with `og.png` (≈ 40 KB each).

### Changed
- **Rebrand.** GitHub repo `LeafarG/ai-digest-site` → `LeafarG/ai-morning-letter`. Vercel project renamed. Cron job renamed. Telegram reply text updated.
- Bare host now `https://ai-morning-letter.vercel.app/`. Legacy `ai-digest-site-pink.vercel.app` kept as courtesy redirect.
- Editorial redesign: story cards, category-coloured kicker pills, serif body, "Coming up" callout, dark-mode parity, monthly card grid archive.

### Fixed
- HTML `<title>` em-dash (U+2014) byte-verified after every render — caught and fixed the 2026-07-26 mojibake regression.
- Archive page intro overlap (`.archive-intro` had a `margin-top: -1rem` that pulled it up over `.lead`).

### Infrastructure
- `publish_site.js` now POSTs the bare brand alias to the new prod deploy after every publish (Vercel doesn't auto-attach the bare alias after a project rename).
- All PowerShell curl calls now spawn `curl.exe` directly (bypassing the `Invoke-WebRequest` alias).

## [1.x] — 2026-07-26

- Initial public site (`ai-digest-site-pink.vercel.app`).
- 19 backfilled editions from the legacy `projects/ai-digest/digests/` PDF flow.
- Vercel auto-suffixing because the bare `ai-digest-site.vercel.app` was held by an unrelated Astro project.
- Cron: `daily-ai-digest-0600-brt` (06:00 BRT).
- Telegram delivery: PDF + one-liner URL.
- Mojibake in legacy HTML `<title>` (em-dash lost).
